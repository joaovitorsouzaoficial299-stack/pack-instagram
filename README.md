# Packê — Packs para Instagram

Primeira versão de uma plataforma de catálogo e personalização de posts para Instagram.

## O que já está nesta versão
- Catálogo com packs e categorias
- Busca por nome/categoria
- Favoritos locais durante a sessão
- Editor ao vivo para texto, subtítulo e cores
- Download do design em SVG
- Layout responsivo para celular e desktop

## Rodar localmente
```bash
npm install
npm run dev
```

## Build de produção
```bash
npm run build
npm run preview
```

## Estado do projeto
Esta é a primeira entrega visual/interativa. Ainda não há autenticação, banco de dados, salvamento permanente, checkout ou geração por IA. Os packs e favoritos são dados locais de demonstração.

## Próximas etapas
1. Validar o build e publicar uma prévia.
2. Definir o projeto Supabase correto e adicionar schema/RLS antes de guardar dados de usuários.
3. Evoluir exportação para PNG e salvar projetos.
4. Avaliar geração com IA somente após confirmar uma opção gratuita sustentável.

## Hospedagem
A hospedagem gratuita deve ser tratada como prévia/protótipo. Confira as condições comerciais do provedor antes de vender acesso ou operar comercialmente.
